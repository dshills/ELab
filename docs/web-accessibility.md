# Web accessibility qualification

November 4, 2026, maintained web interface.

The schematic, inspector and instruments have keyboard skip links. Choose a part
from Parts, use arrows to position its preview (10 drawing units, or 100 with
Shift), Enter to place, and Escape to finish. Preview movement does not move the
previous selection. In Wire mode, Tab reaches named terminals; Enter chooses each
end. Select mode arrows move the selected group. Text fields retain ordinary
editing shortcuts. Inspector/instrument tabs use arrows, Home and End.

Circuit-check targets describe their associated cause and corrective advice.
Selection and agent status messages, the run button and unchanged cursor readings
avoid repeated writes during polling. Pointer preview movement does not stream
live announcements. Recorded analysis uses valid term/description groups, named
dialogs and native disclosure controls.

The automated journey uses actual Tab/Enter/arrows and text entry, without
injected focus, clicks or command mutations: new drawing; source/resistor/
capacitor/reference placement; all four wires; resistance edit; named save;
capture; exact sample selection; timing analysis; Escape and focus return.
Accepted engine snapshots verify the circuit and result. On macOS WebKit, the journey uses documented Option-Tab to include all controls
without changing the owner’s browser preferences. Three browser engines
also exercise modal naming, composition, tab navigation, narrow layouts and
serious/critical axe findings. These are engineering checks, not a claim of
complete WCAG conformance or participant usability acceptance.

A disposable Chrome desktop session verified the skip link and named circuit
controls through the macOS accessibility tree. The direct VoiceOver check remains
unqualified: browser-scoped Command-F5 did not start VoiceOver, and automatic
approval rejected native Chrome inspection because another profile contained
unrelated owner work. No privacy/permission settings were changed, no unrelated
tabs were manipulated, and the owned ELab tab/host were closed normally. Do not
turn this limitation into a request for the novice owner to qualify electronics.
A suitably isolated native screen-reader session is still needed for spoken
output and VoiceOver-specific navigation evidence.
