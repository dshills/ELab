# Captured schematic print preview

Use **Print preview** in the component rail. It replaces the drawing pane with a captured white-paper page. Preview puts page settings in the left rail and temporarily hides the live scope and summary cards to leave room for the page; returning restores those panels without changing acquisition or visibility preferences. The Output page controls supply A4/Letter, orientation, margin, grayscale/color, fit or explicit scale, and optional live overlays. **Refresh preview** captures current settings and source; **Back to circuit** releases the image. Editing remains available in the Inspector and through agent commands. A source/settings change shows “source changed; refresh to update” while preserving captured pixels.

The preview and PNG/PDF file output use the same captured schematic renderer. Preview pixels are a 150 DPI PNG; the native image uses Vellum's immutable tiled image and contain fit. PDF remains vector output. Existing **Export PDF** exports the current editor source; it does not export an older preview. Use **Print all N pages** to submit all pages of the shown capture; see [printer jobs](printing.md).

## Shared commands

| Command | Parameters/result |
| --- | --- |
| `print.preview.start` | Optional `page` override; omission captures Output page defaults. Returns admission snapshot. |
| `project.inspect` / `events.poll` | Inspect `print_preview`: stable ID, queued/running/canceling/completed/canceled/failed status, visibility, source freshness, page, captured run/electrical/document identity, actor, dimensions, size, SHA-256 and failure. Completion publishes `preview`. |
| `print.preview.image` | Exact preview `id`, optional byte `offset` and `limit` (default/max 65536). Returns base64 PNG chunk, offsets, total and digest. Query is read-only and returns owned bytes. |
| `print.preview.cancel` | Exact active preview `id`; requests cancellation. |
| `print.preview.close` | Exact current preview `id`; cancels active rendering, hides the pane and releases retained bytes. An old ID cannot close a newer preview. |

Mutation revision/document guards and retry semantics are unchanged. Preview completion does not advance the command revision. `simulation.wait` retains its existing simulation/project-work semantics; use inspection/events to await preview completion. One render worker is admitted at a time, with an 8 MiB encoded-image limit and a cooperative 30-second context deadline. Closing/canceling does not admit another worker until the old worker finishes. Application close cancels and joins rendering. CoreGraphics calls can only observe cancellation at their existing checkpoints; the deadline is not preemptive.

`source_current` compares document generation, graph/experiment settings and source annotation content; default-page captures also compare current page settings. Explicit page overrides are independent of later default-page edits. Opt-in live overlays additionally compare captured display/readings, so live numeric changes can stale that preview. View pan/zoom and theme changes do not alter a captured page. Snapshot/event payloads contain metadata only, never the image. Native decoding verifies chunk identity, size, digest and dimensions off the UI owner thread, then publishes only if the same preview is still open.

The macOS cgo page renderer is required; unsupported builds return `unsupported`. Incomplete drawings are allowed. Existing explicit-scale fit errors remain explicit. Printer discovery, explicit selection and submission are covered by the separate [printing contract](printing.md). Bounded tiled output is available. Physical output and universal crowded-page readability remain unqualified.

Validation includes captured PNG/export byte parity, edits during blocked rendering, owned chunks/pages, stale IDs, cancellation and close joining, timeout classification, bounded discovery, shared native controls, hidden-canvas gesture refusal and an actual packaged native smoke. The public [demo](../scripts/print-preview-demo.py) exercises both stdio and native socket transports. Visual evidence and exact release checks are recorded separately.

Tiled output uses the same captured source and settings across all pages. **Previous page / Next page** invoke `print.preview.page.set {"id":"preview-1","index":1}` with a zero-based index. A changed page admits rendering under a new preview ID; old chunk IDs refuse. `page_count`, `page_index`, `rows` and `columns` describe the captured grid. Only one page image is retained at a time. **Save shown PNG** exports those exact captured bytes through `export.schematic.png {"preview_id":"preview-2","path":"..."}`, including after later circuit edits. No page/DPI override applies to a captured PNG. Print submits **all captured pages**, regardless of selected page. [Full tiled contract](tiled-output.md).

## Discoverable lifecycle and image contracts

Filtered discovery adds `captured-print-preview` state contracts for Start, Cancel, Close and Image. Start accepts `{}` or optional/null `page` and `page_index`. A null/omitted page captures Output defaults; an object replaces them for that capture, resetting its omitted fields to built-ins. A null/omitted index selects zero. Negative indices refuse at admission; an index above the actual captured page count fails rendering with `preview-failed`. Refresh replaces the previous ID immediately, including when later rendering fails; the old image is not restored.

`source_current` means captured source/settings still match; it does not mean pixels exist. Readiness requires the exact ID, `visible:true`, `status:completed` and retained bytes. A stale completed visible preview is still readable/exportable as captured. After Close, metadata/status/dimensions/ID remain, with visibility false and bytes/hash cleared. Image for that same closed ID returns `not-ready`; an ID replaced by refresh returns `not-found`. Repeated Close for the same retained ID is accepted. Cancel requires an active matching preview and otherwise returns `unavailable`; repeated Cancel while still canceling is accepted. Cancel/Close do not release a blocked renderer slot until it actually returns.

Image accepts offset from zero through the complete byte count, inclusive. Offset exactly at the end returns empty `png_base64`, with `next_offset == total`; stop there. Offset omitted/null means zero; limit omitted/null/zero means 65536, while nonzero limits must be 1–65536. After structural decoding, ID/readiness checks precede range checks. Assemble chunks of one ID, verify the whole-image SHA-256, and restart if the ID changes. The query returns owned memory without IO, rendering, mutation or waiting. Snapshot/event metadata never includes the full image. [Lifecycle/reference workflow](../scripts/preview-contracts-demo.py) and [validation receipt](validation/preview-contracts-validation.json) retain exact source/image evidence and qualification limits.
