# Hobbyist component expansion

Work authorized October 24, 2026, in this order. Each item requires shared
native/agent commands, live simulation, working examples, electrical and
persistence/recording tests, symbols/exports and a documented model contract.
Existing integration limits and the qualified release remain preserved.

1. Complete: common-cathode seven-segment display and powered combinational
   BCD decoder; a real 555 timing capacitor clocks a decade counter/display.
2. Complete: normally open momentary pushbutton, deterministic optional contact
   bounce, explicit press/release, manual counter/reset and debounce examples.
3. Complete: powered comparator with hysteresis, threshold detector and
   analog-to-logic examples.
4. Complete: relay coil dynamics, isolated switched contacts, transistor driver
   and flyback protection examples.
5. Complete: linear voltage regulators with finite load regulation, dropout,
   current limiting and practical supply examples.

Models are educational functional models, not fitted package/device ratings.
Use published manufacturer references for background and declare all choices.
Validate each feature before proceeding to the next; run broad regression and
complete native packaging checks after the combined changes.

All five groups are implemented and validated. See the [combined checks and package receipt](validation/component-expansion/README.md).
