  permanent-menu/local-field control succeeds locally but reproduces the Save
  shortcut failure; menu Select All replaces the name. No app focus/menu cause
  or repair is established. Rate and precise OS parser-queue controls remain
  unavailable through the documented tool scope.
- Default execution denies Unix socket binding with EPERM. Authorized local
  socket gates use the available execution route. The source ledger deliberately
  rejects old hashes and is regenerated after route review.
- The first geometry probe has a non-catalog NPN ID in four cases; corrected
  circuit IDs reproduce movement independently. One wrong-directory redirect
  never runs a test. Initial fixture settings use an invalid command, then omit
  Restart after invalidating a paused run. These setup errors are excluded.
- A long initial flasher layout probe explicitly reaches the unchanged integrator
  time budget. The final relevant geometry fixture uses shorter accepted samples
  and ordinary slower playback, then genuine live integration. No solver limit
  changes. An intermediate single-label full pass is superseded by the final
  two-row source and its new complete qualification.
- A later parallel legacy flasher step fails with an opaque error pointer. Its
  precise cause is **unestablished**; the earlier explicit time-limit observation
  is not its diagnosis. Three isolated repeats and both full final sequential
  suites pass. [Harness review](harness-review.json) records a comment-only
  correction with identical Python AST; original execution recipe is retained.
- The first /270 endurance run is interrupted after 161 cycles /1,602 seconds.
  The owner confirms **“Yes, I closed it.”** AppKit records mouse-up/window-close

  controller loses that detail after a forwarding-client cleanup error.
  [Classification](native-interruption.json), [system log](native-end-log.txt),
  [interrupted report](candidate-workflows-interrupted/report.json.gz).
