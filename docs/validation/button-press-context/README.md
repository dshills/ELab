# Held button keeps its originating command context

October 18, 2026. Review /146's private SDK `ade66eb` retains a button's pressed state across repaint but runs the latest descriptor callback at release. A held **Close switch**, followed by an agent closing that same switch and repainting, runs **Open switch** on release and reverses the agent's edit. A held **Undo** also borrows a newly rendered agent history tip and its permission. Both schedules fail against the prior pin in [before.txt](before.txt).

`desktop/button_context_offscreen_test.go` uses production inspector/history descriptors, measured widget geometry and the pinned framework's exported Manual pointer/keyboard router. The test keeps the same document, selected part and native incarnation. Exact snapshot equality proves old releases preserve the intervening command, including history. The shared conflict/history refusal messages prove the old callbacks reached their guards. Fresh input still acts on the current button. Held Pause also accepts real live-clock publication and repaint without losing the accepted simulation time. The separate mounted RC switch case matches the public agent command's graph, desired/applied contact state, capacitor state, trace and next-step event. Paused contact changes preserve committed charge/time and remain visibly pending until the next step.

The isolated adapter repair captures the originating action on ordinary left-button press, consumes that binding on click, and retains it through queued owner delivery. Existing ELab revision/document/history guards can then refuse the stale action. Native Click is cloned from MouseUp into a Base event: its mouse button survives although HasPos does not. The regression uses that real clone path. Placement sources keep their established handling. Keyboard/programmatic activation keeps the established current-callback contract; a canceled pointer press does not poison later keyboard input or the next pointer press. Disposal retires the pointer binding and queued callbacks retain existing disabled/lifetime checks.

An initial broader callback snapshot changed existing programmatic-click behavior; the framework's icon/reconciliation tests caught this. The final repair is limited to held pointer bindings, and those unchanged contract tests pass. Framework tests also cover a queued pointer click, nil originating action, cancellation/fresh input, disabled controls and disposal. [Isolated consumer results](isolated-after.txt) include the previous slider/text/numeric/Apply suites.

This is deterministic real-widget routing, not physically interleaved OS input or window-deactivation evidence. It does not close visible p95, IME, complete VoiceOver, exhaustive mounted conformance or the owner walkthrough. The immutable /146 package remains affected until a separately qualified replacement is handed over. The canonical app and previous reviews are preserved.
