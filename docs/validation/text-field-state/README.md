# Private text state belongs to its document and selected object

October 18, 2026. **New release blocker reproduced.** The earlier actual native replacement check removed the old field before remounting it. It did not cover a coalesced redraw retaining the same field ID and controlled text.

With the prior SDK and ELab source, the real offscreen pointer/keyboard router retains native incarnation 2 with private `2.2k` text after either loading/reselecting in another document or selecting another 1 kΩ resistor. Return then changes the new owner's public editor draft from `1 kΩ` to `2.2k`. This is a draft-targeting defect; the reproduction does not claim a physical OS interleaving or an automatically changed resistor without Apply.

The repair adds the optional SDK `TextStateKey` contract only for managed TextFields. A changed key remounts that field while keeping its public ID. Other kinds must leave it empty; grids/trees/editors keep their established caller-model identity rules. ELab assigns document generation to text fields and component identity to text fields inside the selected-object inspector. Command revision is not part of the key, so ordinary repaint, solver publication and own accepted edits do not discard a valid draft. Callback revision/generation guards are retained.

The regression extracts the production component inspector descriptor and binds production field context. It types through the real event router, performs public agent commands before a frame, and observes the native incarnation and private value. The fixed cross-owner cases remount as incarnation 3 with `1 kΩ`; explicit pointer focus plus Return cannot publish the old text. Fresh `3.3k` typing/Return still accepts one draft command without mutating the circuit. An unchanged-repaint control retains incarnation 2/private `2.2k` and commits normally. Existing slider, running charge, keyboard focus and agent replay checks also pass against the isolated source.
