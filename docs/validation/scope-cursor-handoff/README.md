# One cursor click accepts its own time-field commit

October 18, 2026. A new real-widget test reproduces a normal /147 interaction failure: type `4 ms` into cursor A, then click B once. A commits at 4 ms, but selecting B refuses with `expected command revision 5; current command revision is 6`. Enter followed by a separate B click works. [Before](before.txt).

The repair scopes continuation to the two cursor time fields and their four Select/Clear buttons. It records only consecutive accepted cursor-field response contexts. A rendered action may advance within that exact span only when its document and the current command context still match. Agent edits, unrelated user fields and document replacement break the span; failed cursor commits clear it. It never adopts a later service snapshot as proof that another actor's command was its own. Shared commands, public IDs, model behavior and the project format are unchanged. SDK `677548d` is unchanged.

The mounted tests use production `cursorControls`, actual retained TextFields/buttons, measured pointer targets and the pinned Vellum Manual event router. The fixture arranges the six controls in two rows without replacing their callbacks. RC and mixed NPN flasher cases type quantity text, preserve private input through ordinary repaint, commit on Enter, select B and clear A, comparing the complete Scope against a separate public-agent service. Known intervals are 4–16 ms (12 ms) and 100–260 ms (160 ms), with reported reciprocals 83.333… Hz and 6.25 Hz; these arbitrary cursor intervals do not measure the waveform period. Circuit topology, committed traces/physics, run identity, document and history must remain unchanged by measurement.

[Mounted results](mounted-after.txt) also cover single-click focus-loss Select and Clear, plus a held selection across an agent edit/repaint: the stale release reaches the shared conflict guard and preserves the exact snapshot; a fresh click works without changing the agent's cursor time. [Semantic continuation checks](continuation-after.txt) cover original/intermediate rendered actions, both own fields, agent-before/after, another user field, document replacement and a failed out-of-history commit.

The source auditor now recognizes the cursor-action factory's command argument, with explicit literal/dynamic/unknown-route tests. [Ledger review](ledger-review.json) preserves all 162 command IDs/aliases and 132 routed IDs. Four old sites move/change into seven sites; every other site differs only by location. Totals are 63 production sources, 392 sites and 150 requiring binding review; these remain syntax counts, not exhaustive runtime acceptance.

This is deterministic offscreen widget routing. It does not qualify physically interleaved OS input, complete menus/focus/IME/VoiceOver, visible p95 or the owner walkthrough. Existing /147 review packages remain immutable and affected until a clean replacement is separately qualified.

Deferred native commits are also covered: Select/Clear settles both current time fields before dispatching. A phase-indexed owner-held transaction advances only from its own accepted responses, suppresses duplicate activation/completion and refuses rebound/intervening contexts before a deferred field dispatch can overwrite agent work. Admission/completion failure and invalid time suppress the final action. The mounted fixtures use the real `cogent.SettleTextField` API. [Deferred-order failure before completion support](deferred-before.txt) and final focused results are retained.

The native mixed smoke now waits for the mounted document and real cursor settlement to complete before pointer placement and assertions; numerical assertions and deadlines are unchanged. The earlier immediate assertion failure and successful corrected run are retained.
