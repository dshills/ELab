# Live cursor private input belongs to its simulation run

October 18, 2026. A live cursor draft can carry into an agent-restarted run through a freshly rebound native field. The source repair scopes the existing cursor controls to their live run, preserving ordinary editing and sampling. Public commands, models, project format and SDK remain unchanged. Clean replacement packaging is pending; the preserved /156 executable does not contain this repair.

## Reproduction

Start a paused RC trace with 20 ms retained history and an unset cursor. Type a private `8 ms` value without committing. An agent restarts the same document and steps the new run to 20 ms before one redraw. The controlled field remains empty in both runs, so the old native text widget retains its private draft. Clicking that field and pressing Enter commits 8 ms through the new run’s freshly bound callback, despite the user having typed it for the earlier run.

Both cursor A and B fail: run 3→4 keeps native incarnation 4→4 or 8→8; Enter advances revision 7→8 and places the cursor at 8 ms in the restarted run. Same-run repaint and one additional same-run sample correctly preserve the draft and pass as controls. The [before log](before.txt) retains the actual failing state, not just an incarnation assertion. Production source at that reproduction matches the preserved /156 `probes.go` hash; this is mounted native routing evidence, not a new physical OS reproduction of those package bytes.
