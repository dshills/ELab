# Inspector usability — October 29, 2026

This is the first implementation batch from the current competitive comparison.
Common value edits and Plot actions precede detailed model settings. Op-amp live
readings retain their established position immediately above the compact Plot
rows. Long model-control checkbox captions are shortened, with explanations in
Help. Configured transistor explanations stop asserting default gain, no heating
or instantaneous junction response; base-model limitations are labeled as such.
Plot help now accurately describes the six-trace refusal instead of eviction.

A mounted field-to-Plot regression reproduced a real stale-action refusal. The
repair reuses the existing value-related action settlement and revision guards:
the draft can finish without configuring the component, and a held action cannot
adopt another agent's edit or a replacement document. The public commands,
solver/model implementations, limits, modules and SDK remain unchanged.

## Native observations

Two isolated, ad-hoc signed development candidates were used. In `native-reviewed`,
RC inspectors were visually checked in all four themes; System resolved dark.
A CUA-driven value draft `2uF` followed by one Plot current click added `i:C1`
while the configured capacitor remained 1 µF. Native wheel scrolling reached
lower content and returned; thumb dragging exposed readable ESR/leakage/startup
controls. The Apollo amplifier model option was readable and a native click
opened the existing profile fields. No owner project or session was used.

The final production change after those observations only corrects conditional
transistor explanation/assumption text. `native-final` was rebuilt from final
production source, configured through the public profile command with beta 200,
and its explanation was visually checked after a native thumb drag. Its exact
executable identity is in source-inputs.json; final model AX text is retained.
The final complete rendered suites cover final source across themes.

All owned fixtures closed normally (exit 0). Recovery/appearance persistence was
disabled and a test sandbox denied shared Cogent Core geometry writes. The logged
geometry denial is an intentional fixture protection, not an app regression.
The existing duplicate-objc linker warning remains. No release package was
promoted, overwritten, pushed or uploaded; qualified /282 and earlier bytes stay
preserved. These development bundles are not newly qualified distributions.

Initial one-page wheel attempts did not visibly move the focused inspector;
after focusing neutral content, a five-page down and three-page up visibly moved
it. Thumb dragging independently reached detailed controls. The pixel option was
rejected by CUA because macOS accepts pages. These observations do not establish
hardware-rate scrolling or close native acceptance checks 3/6/9/11. The first-use
participant study remains unrun; no novice-success or competitive ease claim is
made from internal tests.
