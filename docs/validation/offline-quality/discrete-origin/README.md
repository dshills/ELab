# Discrete input callback origin

October 25–26, 2026. Five assembled ELab controls reproduce queued input
adopting an intervening public service agent's newer context: output Color,
locked motor, voltage-color keyboard button, diagnostic disclosure and the
component list. Each original KeyChord is dispatched with a one-event budget
while owner delivery remains queued. An agent changes output margin, motor
resistance, display range or editor draft. A benign routed move refreshes the
retained descriptor before owner delivery. Every corrected baseline case then
performs an unintended new user command. [Before](before.txt).

These tests use actual assembled callbacks, ownership keys and platform
adaptation in a minimal host, with real driver queues and shared service agent
commands. No callback is substituted. They are rendered/routed checks, not
precise native macOS queue or hardware-rate acceptance. Initial fixture errors
(overriding polished control size bounds and not selecting the Document
inspector for a display control) are retained separately; product code is not
changed to accommodate those fixture mistakes.

SDK elab8 captures admitted checkbox and single-list-selection callbacks,
disclosure proposals and keyboard-origin button activation. Existing pointer
button origin remains. Genuinely programmatic Send(Click) retains its established
latest-binding contract, as do Switch/ToggleButton, selectors and non-list choice groups. Existing
list eligibility, FIFO proposals, disabled/retired controls and disclosure
accepted-state revocation remain enforced. The old list/disclosure tests that
required callback refresh are deliberately changed after these ELab/agent
reproductions demonstrate the unsafe behavior. Fresh independent input succeeds
for all five controls after refusing the stale event.

Scope begins at event admission; this batch does not claim that all controls
capture their callback at pointer-down or that every accessibility/native menu
path has been qualified. Already qualified slider/divider/pointer-button
contracts remain separately tested. No components, public commands, electrical
models, project formats or solver limits change. All prior SDK archives and
qualified /266, /265, /264, /260 and /205 packages remain preserved.

Status: focused ELab and framework regressions pass on isolated repaired SDK
source 0650083e, elab8. Complete source/dependency qualification is in progress.
Original native acceptance checks 3,6,9,11 remain open with their prior limits.

The initial elab7 candidate also changed unused Switch/ToggleButton callback
