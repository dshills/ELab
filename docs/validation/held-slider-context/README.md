# Held slider preserves its originating command context

October 18, 2026. The previous private SDK (`bc6b456`) lets a retained potentiometer drag overwrite an intervening agent edit after repaint: the agent sets **20%**, then releasing the old drag writes **94.0625%**. Loading another saved document with the same component IDs is also overwritten. This is a release blocker, independently of the pending owner walkthrough.

The test uses Vellum's exported offscreen Manual adapter with real retained native widgets, measured geometry, its pointer event router, bounded manual clock and owner scheduling. ELab supplies its production potentiometer descriptor and `bindFieldContext`; the test does not substitute a callback. It holds the pointer, performs the public agent command, forces a frame, then releases. Domain snapshots must remain exactly equal after refusal. Uninterrupted and unchanged-repaint controls each commit one user command.

The repair in private Vellum commit `88dc650884f97629a6370e8408fd9e9242f1a7e0` captures the descriptor callback at slider gesture start and carries it through release and queued owner delivery. ELab's existing revision/document guards then refuse the old edit. A final SlideStop listener retires the binding after the native slider emits Change; disposal also retires it. Later independent slider changes use the current callback. Discrete control semantics are preserved.

Only `drivers/cogent/controls.go` and the new `control_context_test.go` differ from the prior SDK. The [member comparison](sdk-diff.json), [source patch](vellum.patch), [raw commit](vellum.commit.txt) and [prior lock](prior-sdk.lock.json) retain reconstruction evidence. Prepared upstream/typesetting files and all five bootstrap sources are unchanged. The sibling Vellum checkout and existing prepared SDK caches were not edited.

The consumer regression is `desktop/slider_invalidation_offscreen_test.go`, run by `scripts/check.sh` under `-tags=offscreen -race`; tagged vet also runs. The normal lint/imports/Staticcheck, Python tests and root/native race/vet remain required. [The checkpoint](checkpoint.json) records the passing final results: framework driver race/vet; focused offscreen race/vet; full consumer audit freshness, lint/Staticcheck, 43 Python tests, root/native race/vet and the new tagged regression/vet. [Before](before.txt), [isolated after](isolated-after.txt) and [full consumer gate](full-check.txt) are retained.

This is deterministic retained-widget/event-router evidence. It does not claim a physically interleaved OS pointer test, running/focus-loss/IME/screen-reader acceptance, visible latency or exhaustive mounted control coverage. Review /143 remains immutable and affected until a separately qualified replacement is handed over; the canonical app remains unchanged.
