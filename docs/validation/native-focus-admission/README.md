# Observe native focus completion after an admitted request retires

October 18, 2026. The candidate /147 and current /146 comparison failures are preserved in the preceding [candidate checkpoint](../../../research/ui-audit/first-version/button-press-candidate-checkpoint.json). A thread sample located repeated native accessibility walks, but did not prove that an individual traversal exceeded the deadline.

A diagnostic-only isolated SDK build measured approximately 280 managed nodes and 65–69 thousand hit-tree visits per complete probe, taking approximately 14 ms. The [measurement log](probe-counts-before.txt) shows repeated completed queries. This rules out the earlier inference that one slow traversal explains the five-second failure. No tree-performance patch is shipped.

A minimal diagnostic then captured the decisive interleaving: `AXFOCUS retired on owner node:dmFsdWUtZW50cnk 4 5`. The native focus request was admitted against generation 4, but an ordinary semantic publication advanced to 5 before owner delivery. The framework correctly refused the obsolete request. The [native refusal log](native-refusal-before.txt) ends in the same inspector timeout. Existing SDK `TestAccessibilityAdmissionBoundedStaleAndRetired` explicitly preserves this contract: queue admission does not promise action completion. Diagnostic patches are retained, and the isolated checkout was restored byte-for-byte to pinned `677548d`; caches, dependencies and sibling Vellum are unchanged.

The defect was in ELab's smoke protocol: it requested focus once and waited for completion without recovering from a permitted admission retirement. The corrected waiter observes the current native target, retries only idempotent focus, and requires the current native ID to be actually focused before continuing. Reachability, native-window presence, enabled/nonpending state, positive geometry and exact center hit testing remain mandatory. The existing shared five-second deadline and 20 ms polling interval are unchanged. Value setting and Apply are still issued once and must satisfy their original graph and numerical checks. No application command, user workflow, model or project format changes.

The [extracted previous wait regression](wait-before.txt) fails both before-queue refusal and after-admission retirement. The current tests also reject admission without completion, stale focused IDs, unavailable/obscured targets, late observations after cancellation and native query/action errors. Already-focused controls require no extra request. Native evidence records request/admission counts, observed focus ID and generation, so a passing run cannot merely assume an admitted request worked.

The source change is confined to smoke validation and its tests. It does not justify another product version increment. The corrected /147 bytes will use a separate `147-focus-review` folder; the original unqualified candidate and all earlier reviews remain immutable. Full quality and exact copied-runtime qualification must finish before that folder becomes an owner handoff. Physical OS interleaving, VoiceOver, visible p95, supported installation and owner acceptance remain separate gates.
