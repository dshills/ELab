# Native menus

On macOS, File, Examples, Theme and all Inspector/scope dropdowns open AppKit menus. Native menus supply their own appearance, rounded material, scrolling and keyboard navigation. Selectors and Theme check the selected option. The app menu bar is installed through Vellum’s service after the window is ready. Theme uses Vellum’s controlled check-action metadata; passive separators are supported by the native bridge and cannot dispatch commands. Other platforms continue to use valid Vellum action menus and selectors.

Vellum owns the trigger controls and layout. Each native popup transports only a stable option index back to the original selection callback on the application owner. The callback retains the original event kind and controlled check-action value. Users and agents therefore retain the same domain commands and file/history guards. Native menus are asynchronous on the main thread and limited to eight pending callbacks; selection or dismissal releases each callback.

The menu captures the descriptor’s command revision and menu serial. Stale descriptors cannot open or apply choices, disabled/unlisted choices are refused, and agent edits during menu tracking invalidate the captured menu. The captured revision also reaches atomic shared-command admission, refusing an agent mutation interleaved between the popup predicate and its callback. Live simulation samples do not change that command revision. A stale refusal leaves state unchanged; the next refreshed descriptor can open a new menu.

Accessible trigger help preserves existing help and includes the current choice. Triggers publish as Vellum buttons, while open choices publish through AppKit accessibility. Observed native mouse selection, type-ahead/Return and Escape are recorded in the [visual ledger](../research/ui-audit/native-choices/README.md). This is not a full screen-reader, keyboard, IME or cross-platform certification. The application menu bar’s theme entries do not yet publish current-theme checkmarks; the in-window Theme menu does.
