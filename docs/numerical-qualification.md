# Electrical reference qualification

`elab-conformance --electrical-suite` runs the ordinary construction/save/reopen workflows and an additional numerical suite through public commands. It creates owned empty sessions; it does not attach to user projects. The external stdio, headless socket and optional packaged-native adapters must match the in-process numerical evidence.

```sh
./scripts/build.sh
./build/elab-conformance --electrical-suite \
  --artifacts build/electrical-reference-new \
  --native-binary build/ELab.app/Contents/MacOS/ELab
```

The output directory must be new. `report.json` and per-adapter `electrical/electrical.json` contain the frozen-reference digest, measured values/errors/tolerances, flasher sample counts, graph hashes, crossing brackets and backend Verify timings. Existing CLI behavior without the flag is retained.

## Independent references

The checked-in [reference fixture](../internal/conformance/testdata/electrical-reference.json) is generated by [a separate standard-library Python program](../scripts/freeze-electrical-reference.py). It imports no ELab code and invokes no ELab solver. At 70-digit Decimal precision it uses Newton on LED current, simultaneous damped 2×2 Newton for reciprocal-transport Ebers–Moll base/collector KCL, and closed-form convolution for ideal and linearly ramped RC forcing. The original qualification used ELab’s DC bisection and waveform backward-Euler kernels. The unreleased [capacitor-method update](capacitor-integration.md) retains these independent reference equations while advancing general capacitor integration to SDIRK2. The reference freezes exact model parameters and source timings before qualification.

`python3 scripts/freeze-electrical-reference.py` verifies exact reproducibility. Only explicit `--write` regenerates the fixture; model/reference changes must be reviewed. These are independent implementations of the same pinned educational equations, not measured-device data or separately configured SPICE outputs.

The suite checks:

- 5 V LED with 1 kΩ/2 kΩ: 1% current/voltage agreement, independent KVL and public branch-current KCL.
- Grounded-emitter NPN with 10 kΩ base/1 kΩ collector load: off, active and saturated operating points; max(1 mV, 1%) voltage and max(1 nA, 1%) current tolerances; conservation and exact model parameters.
- NPN ideal pulse at default/half sample interval: independently frozen on/off values and both sides of repeated source edges, including 150 ms. There is no intrinsic device delay in this model.
- 10 kΩ/1 µF RC with 0–5 V ideal pulse: predefined samples, both edge sides, exact capacitor continuity and settled periodic extrema near 33.464 mV / 4.966536 V. Voltage tolerance is max(1 mV, 0.1%); current tolerance uses that voltage bound divided by resistance.
- The same RC with 1 ms linear rise/fall, included within 50 ms high/low phases: closed-form finite-rise samples at default 1 ms and half-step 0.5 ms. Source/model/settings mismatch fails before numerical acceptance.
- Two-capacitor/two-NPN LED flasher: two seconds at 1 ms, 0.5 ms and 0.25 ms output intervals. Public paused Step collects chunks smaller than rolling-history bounds and checks no samples are missing. Current crossing times are reported as sample brackets; median settled period and current/capacitor extrema must remain within declared refinement tolerances. This compares one adaptive kernel with itself, not an independent flasher implementation.

The flasher refinement limits are max(two coarse sample intervals, 1%) for period, and max(1 µA, 1%) for current extrema or max(1 mV, 1%) for capacitor extrema. Both adjacent refinement pairs are checked. Backend 200 ms Verify times are observed once per flasher resolution; they do not establish p95 visible acknowledgment, edit-to-result latency or a universal performance promise. Verify must preserve the paused live state.

## Defects found and repaired

An ideal pulse corner computed as `0.15000000000000002` lay just beyond an output boundary of `0.15`. The input changed, but RC/NPN traces could lose the left side. Shared corner handling now reconciles only four floating-point ULPs, retains both sides, and keeps genuinely earlier samples on the earlier input. RC, NPN and mixed-kernel regressions cover repeated corners and capacitor continuity.

The independent finite-rise RC reference also found a 1.35 mV error at 75 ms. Waveform-network relative integration tolerance is now four times tighter. An error-based step controller targets 0.75 of the accepted full-versus-two-half error ratio, with bounded growth, instead of waiting for binary doubling. Every proposed step is still checked. The original absolute startup tolerance, Newton model, backward-Euler method, 512-attempt/100 ms integration budget and public sampling limits remain enforced. Overly tight initial candidates exceeded the work quota and were rejected rather than weakening that quota.

The [release receipt](validation/electrical-qualification-validation.json) and [four-adapter evidence](validation/electrical-qualification-conformance.json) record the actual build and coverage. Repeated reference-fixture backend timings are covered by the separate [performance qualification](performance-qualification.md). General PVT/device calibration, independent nonlinear flasher/SPICE comparison, broader waveform/circuit qualification, visible/capacity performance, clean distribution and participant gates remain separate work.


The 0.98.0 [high-pass experiment](rc-high-pass.md) adds analytic positive/negative pulse checks outside the frozen release table. It exposed cancellation error at a small output node despite acceptable error relative to a larger stored capacitor voltage. Non-waveform coupling capacitors now check both non-ground node voltages as well as stored voltage; grounded, waveform and mixed RC/NPN error paths retain their existing settings. A rejected blanket tightening exceeded existing potentiometer/switch work budgets; the final node check keeps all work limits and passes those regressions. The existing four-adapter 294-check suite and flasher refinement are repeated; high-pass public comparisons and forty timed 200 ms captures supply separate evidence for the new experiment.
