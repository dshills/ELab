# ELab documentation

Start with the current [web workbench](web-workbench.md),
[feature/qualification record](web-parity.md) and [agent setup](agent-setup.md).

For the downloadable macOS build, see the [published alpha](current-release.md).

`validation/` records are retained as historical evidence for their exact
revisions. Use the [native archive](native-archive.md) to reproduce those builds;
current build/run/check commands are in the repository README.
