# README screenshots

Real, unmodified ELab window captures from October 29, 2026, using source
`7408ac43`. These are application screenshots, not generated illustrations or
exported schematics. Capture used CUA in a disposable app session with private
runtime state. The owned session closed normally; no owner circuit was used.

- `rc-scope.jpg`: RC charge/discharge in Light, paused at 100 ms, 10/40 ms cursors.
- `spectrum-cursors.jpg`: clipped-amplifier output in Dark, held live FFT of
  0–200 ms, rectangular window, 64 samples, 10 Hz fundamental; A/B at 10/30 Hz.
- `class-ab-apollo.jpg`: the eight-BJT discrete amplifier in Apollo, paused at
  25 ms, with Q6 selected and scope collapsed.

Dimensions and content hashes are in `screenshots.json`. The screenshot bundle
is a development fixture, not a newly qualified release package. Captures show
actual rendered controls/plots; they do not qualify native queue/rate gates.
