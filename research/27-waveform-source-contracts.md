# Complete per-source waveform contracts

The next discovery gap is the pair of complete sine/finite-pulse setters. Existing filtered schemas already describe units and coupled bounds, but omit stateful editing, target/error and completion rules. Both now attach a `per-source-waveform` contract while retaining their original quantity definitions, numeric bounds and relationships. Ordinary catalog/output schemas stay unchanged.

The contract separates complete replacement from partial editing, configured values from accepted stale samples, and a source edit from sampling Fit or independent captured results. Missing targets and wrong kinds are both `invalid-params` here; the finite pulse timing convenience command retains its separate behavior. Configuring an incomplete drawing remains valid and does not promise successful later simulation. No source model, integration method, command ID, capacity/work limit or file format changes.

New controlled tests exercise omitted/null nested fields, constant sine/equal-level triangular pulse definitions, exact no-op preservation, paused charge/time, failed staged edits, one-undo restoration and byte-identical immutable captures. The public waveform quantity/RC workflow now requires both state contracts and checks missing/null replacements and missing/wrong-kind targets alongside its existing analytic waveform/RC and numeric Save/reopen checks.

This changes evidence retention only; application/Go/binary identities remain unchanged. Initial reports, the checker failure, pre-change source hashes and final full quality are retained.
